Deterministic USB/IP Transport for Engineering, Lab & Industrial Hosts.

SnakeUSBIP exposes remote USB hardware over standard TCP/IP and VPN links as native local bus devices. Built around a direct C#/.NET 9 Windows VHCI IOCTL engine (zero child-process spawning overhead), WHQL-signed drivers, and an on-demand TCP/3241 control plane.

01 // SYSTEM ARCHITECTURE

Engineered for Reliability Under Load

01 / IOCTL_ENGINE

Direct Windows VHCI IOCTL

Communicates directly with the WHQL-signed usbip2_ude kernel device handle via Win32 DeviceIoControl, eliminating process-spawn overhead and stdout regex parsing.

02 / CONTROL_PLANE

On-Demand TCP/UDP 3241

Automatic LAN/VPN discovery on UDP 3241, serialized LIST / BIND / UNBIND / STATUS over TCP 3241 with optional IP allowlist and HMAC token auth, plus immediate host release on detach.

03 / KERNEL_HARDENING

Persistence, Diagnostics & SBC Ready

Supports Windows kernel boot persistence, custom USB serials, Virtual Hub port tuning, 1-click diagnostics ZIP export, UAS storage warnings, and Linux usbip-host/dwc2 patches.
